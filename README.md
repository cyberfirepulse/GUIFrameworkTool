# GUI Framework Tool

Desktop tool for Windows to design desktop apps visually and generate working code in Python (Tkinter) or PowerShell (WinForms). Made for cybersecurity education, networking labs and technical work.

## Features

- Visual designer with tabs, buttons, fields, tables and menus
- Generates complete Python or PowerShell apps, ready to run
- Built-in wizards, such as a Cisco configuration tool, a subprocess launcher and a PowerShell tool
- Plugins with extra wizards: network scanner, log analyzer, OSINT, Proxmox, service desk and more
- Example projects to start from
- EXE builder for your generated Python apps
- Interface for licensing, updates and help in English and Dutch
- Your data stays on your computer, in the `data` folder next to the program

## Download

Get the latest installer from the [Releases](https://github.com/cyberfirepulse/GUIFrameworkTool/releases) page. Requires Windows 10 or 11 (64-bit).

Python 3.10 or newer is only needed to run generated Python apps and to build EXE files. The tool itself works without Python.

## License

GUI Framework Tool needs a license key. A free 14-day Evaluation license is available. See [PRICING.md](PRICING.md) for the editions and prices.

The license check only uses your license key and a random installation number.

## Updates

GUI Framework Tool checks for a new version at startup. You decide whether to install it. You can also check manually via **Help → Check for updates…**.
