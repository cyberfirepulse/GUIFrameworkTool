# GUI Framework Tool

Desktop tool for Windows to design desktop apps visually and generate working code in Python (Tkinter), PowerShell (WinForms), C# (WinForms) or Java (Swing). Made for cybersecurity education, networking labs and technical work.

## Features

- Visual designer with tabs, buttons, fields, tables and menus
- Generates complete Python, PowerShell, C# or Java apps, ready to run
- Project templates for lessons: log viewer, network checklist, PC overview, helpdesk, storage, plus exercise templates (form, quiz) where students write the logic themselves
- Built-in wizards, such as a Cisco configuration tool, a subprocess launcher and a PowerShell tool
- Plugins with extra wizards: network scanner, log analyzer, OSINT, Proxmox, service desk and more
- Example projects to start from
- EXE builder for your generated Python apps
- Interface, help, licensing and updates in English and Dutch
- Your data stays on your computer, in the `data` folder next to the program

## Download

Get the latest installer from the [Releases](https://github.com/cyberfirepulse/GUIFrameworkTool/releases) page. Requires Windows 10 or 11 (64-bit).

Python 3.10 or newer is only needed to run generated Python apps and to build EXE files. Generated C# apps need the .NET SDK 8 or newer, generated Java apps a JDK 11 or newer. The tool itself works without any of these.

## Updates

GUI Framework Tool checks for a new version at startup. You decide whether to install it. You can also check manually via **Help → Check for updates…**.
